🎮 Jogo da Velha Neon

Um Jogo da Velha moderno com visual neon, feito em HTML, CSS e JavaScript puro.



✨ O que tem no jogo





Visual neon (X amarelo, O rosa, grade azul brilhante)



Dois modos de jogo:





👥 Com Amigo → joga contra outra pessoa no mesmo computador



🤖 Contra IA → joga sozinho contra o computador



Campo para colocar o nome dos jogadores



Placar que conta as vitórias de cada um



Sem empate: se o tabuleiro encher e ninguém ganhar, o jogo apaga tudo e continua até alguém vencer



Linha de vitória brilhante



Funciona no celular e no computador



Tudo em um único arquivo (fácil de abrir e compartilhar)



🚀 Como jogar / abrir





Baixe o arquivo jogo-da-velha-neon.html



Dê dois cliques no arquivo (abre no navegador)



Pronto! Já pode jogar



Não precisa instalar nada. Funciona no Chrome, Edge, Firefox, etc.



🕹️ Como jogar





Escolha o modo:





Com Amigo ou Contra IA



Digite os nomes dos jogadores



Clique nas casas do tabuleiro para colocar X ou O



Quem fizer 3 em linha (horizontal, vertical ou diagonal) ganha 1 ponto



Use os botões:





Nova Partida → limpa o tabuleiro e continua com o mesmo placar



Zerar Placar → zera as pontuações e recomeça



📌 Observações





No modo Contra IA, o Jogador 1 joga com o X e a IA joga com o O



A IA tenta ganhar e também bloqueia suas jogadas



Se o tabuleiro ficar cheio sem vencedor, ele limpa automaticamente e o jogo continua



🛠️ Tecnologias





HTML5



CSS3 (efeitos neon)



JavaScript (lógica do jogo + IA simples)



Divirta-se! 💜
